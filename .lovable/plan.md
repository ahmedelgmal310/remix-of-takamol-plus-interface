# صفحة «إدخال فاتورة مبيعات»

صفحة جديدة زي الصورة بالظبط، بنفس ألوان وشكل «تكامل بلس» الحالي.

## المحتوى
- **العنوان والأزرار:** «إدخال فاتورة مبيعات» + الوصف، ومسار (الرئيسية › المبيعات › إدخالات المبيعات)، وأزرار حفظ / حفظ وطباعة / إلغاء.
- **بيانات الفاتورة:** رقم الفاتورة INV-000152، التاريخ 2025/09/23، نوع الفاتورة (فاتورة مبيعات)، طريقة الدفع (نقدي).
- **العميل والمستودع:** بحث/اختيار عميل (من عملاء صفحة المبيعات) مع بطاقة العميل (شركة النخبة التجارية #C00125)، المستودع الرئيسي.
- **معلومات إضافية:** رقم المرجع، الموظف المسؤول (أحمد محمد)، ملاحظات.
- **تفاصيل الأصناف:** بحث بالاسم أو الباركود + «إضافة صنف»، جدول بالثلاث أصناف (شاشة سمارت 55 بوصة، سماعات بلوتوث، شاحن سريع) بكمية قابلة للتغيير وخصم وضريبة، وأزرار تعديل وحذف، و«إضافة ملاحظة للسطر».
- **تحت:** ملاحظات عامة، بيانات الخصم (نسبة/مبلغ + السبب)، إجمالي الفاتورة (قبل الضريبة 3,305.00، الضريبة 495.75، الخصومات 40.50، الإجمالي 3,760.25) — كله بيتحسب تلقائيًا.

## التصرفات
- «حفظ» يتحقق من العميل ووجود صنف واحد على الأقل، ويظهر رسالة نجاح.
- «حفظ وطباعة» يحفظ ويفتح الطباعة. «إلغاء» يرجع لصفحة إدخالات المبيعات.
- زر «إضافة فاتورة مبيعات» في صفحة إدخالات المبيعات (الزر الأعلى وفي الإجراءات السريعة) هيفتح الصفحة دي بدل رسالة «قريبًا».
- رابط في القائمة الجانبية تحت «المبيعات»: «إدخال فاتورة مبيعات».

## ملاحظة
الصورة فيها أرقام إجمالية غير متطابقة مع الجدول (مثلاً الصف الأول 2,460 قبل الضريبة بينما 2×1,200=2,400). هحسب الإجماليات من الجدول تلقائيًا فممكن تختلف شوية عن الصورة.
