# صفحة الهيكل التنظيمي

صفحة جديدة «الهيكل التنظيمي» تطابق الصورة، بهوية تكامل بلس الحالية.

## ما سيظهر
- مسار التنقل (الرئيسية ‹ الموارد البشرية ‹ الهيكل التنظيمي)، العنوان والوصف «عرض الهيكل التنظيمي للجهة مع الرواتب والتكاليف».
- أزرار: إضافة قسم، تصدير، طباعة، رجوع.
- شريط أدوات: عرض هيكلي / عرض قائمة، تكبير وتصغير وملء الشاشة، وقائمة «عرض مع الرواتب / بدون رواتب».
- بطاقة الرئيس التنفيذي (د. سعد بن محمد، راتب 50,000، موظف 1) متصلة بخطوط بستة أقسام ملوّنة:
  الإدارة المالية (أ. علي الشهري، 120,000، 8)، الإدارة التشغيلية (أ. خالد العتيبي، 90,000، 6)، الموارد البشرية (أ. أحمد السبيعي، 110,000، 7)، الإدارة الاستراتيجية (أ. نورة القحطاني، 95,000، 5)، تقنية المعلومات (م. عبدالله الغامدي، 130,000، 9)، الإدارة الطبية (د. فهد المطيري، 200,000، 15).
- كل قسم: مدير الإدارة، إجمالي الرواتب، عدد الموظفين، وزر «عرض التفاصيل».
- ملخص أسفل: إجمالي الرواتب 795,000، إجمالي الموظفين 51، عدد الأقسام 6، راتب الرئيس التنفيذي 50,000، والشريط الأخضر «الإجمالي الكلي للرواتب (مع الرئيس التنفيذي) 845,000».

## التفاعلات
- «إضافة قسم» نافذة (الاسم، المدير، الرواتب، عدد الموظفين) والقسم يظهر في الهيكل والأرقام تتحدث تلقائيًا.
- «عرض التفاصيل» نافذة بموظفي القسم (أسماء تجريبية) وإمكانية حذف القسم.
- عرض القائمة يحوّل الهيكل لجدول.
- إخفاء الرواتب يخفي مبالغ الرواتب.
- التكبير والتصغير يغيّران حجم الهيكل، والطباعة والتصدير (ملف CSV) يعملان.

## ملاحظات
- تضاف «الهيكل التنظيمي» للقائمة تحت الموارد البشرية/الموظفين دون تغيير باقي العناصر.
- الصور: الصورتان الموجودتان + أحرف أولى للباقي.
- على الهاتف تتحول الأقسام لعمود/عمودين مع إخفاء الخطوط الأفقية.
- البيانات تجريبية ولا تُحفظ بعد التحديث.
