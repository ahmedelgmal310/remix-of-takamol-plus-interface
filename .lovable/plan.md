# صفحة جديدة: اختيار النظام

صفحة «مرحباً بك في تكامل بلس — اختر النظام الذي ترغب في استخدامه» زي الصورة. الصفحة دي من غير القائمة الجانبية (زي صفحة باقات الاشتراك)، ليها هيدر خاص فيه الشعار والبحث والجرس واسم «مدير النظام». الرئيسية الحالية مش هتتغير، وهيتضاف رابط «اختيار النظام» في القائمة الجانبية تحت «الرئيسية».

## المحتوى
- على الشمال: صورة مكتب مولّدة (مكتب حديث وشباك على مدينة)، عليها «معاً .. لبناء إدارة أكثر كفاءة»، وتحت شكل كحلي فيه نخلة و«نحو مستقبل أكثر تكاملاً».
- على اليمين: العنوان والوصف، وتحتهم 15 كارت (3 صفوف × 5)، كل كارت فيه أيقونة ملونة واسم ووصف وسهم.

| النظام | يفتح |
|---|---|
| التقارير والإحصائيات | التقارير المالية |
| المالية والمحاسبة | لوحة المالية |
| إدارة العقود | مستندات الموظفين |
| التقييم الوظيفي | التقييم |
| الموارد البشرية | بوابة الموارد البشرية |
| الخدمة الذاتية | الخدمة الذاتية |
| المستندات والنماذج | المستندات |
| الإجازات والغياب | طلب إجازة |
| الإجراءات والمخالفات | الجزاءات |
| التدريب والتطوير | التقييم (مؤقتًا) |
| الدعم والمساعدة | الدعم الفني |
| الإعدادات | الإعدادات |
| إدارة المشاريع | المشاريع والمهام |
| المشتريات والمخزون | فاتورة المشتريات |
| خدمة العملاء | لوحة خدمة العملاء |

## التفاعلات
- لما تقف على كارت، إطاره يبقى أزرق والسهم يتلوّن (زي كارت «الموارد البشرية» في الصورة)، والضغط عليه يفتح النظام بتاعه.
- البحث بيفلتر الكروت بالاسم أو الوصف، ولو مفيش نتيجة تظهر رسالة «لا توجد نتائج».
- الجرس بيفتح صفحة الإشعارات.

## الموبايل والتابلت
