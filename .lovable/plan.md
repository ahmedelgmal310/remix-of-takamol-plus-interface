# الصفحة الرئيسية الجديدة

تحويل «الرئيسية» إلى لوحة ترحيب مطابقة للصورة، مع نقل صفحة «سلم الرواتب» الحالية لعنوان خاص بها حتى لا تضيع.

## ما سيظهر في الرئيسية
- بانر ترحيب: «مرحباً، أحمد 👋» و«نحن هنا لمساعدتك في إدارة أعمالك بكل سهولة» مع صورة مكتب (لابتوب ونبات) مولّدة.
- ثلاث بطاقات: موافقات 5 (بانتظار إجرائك)، طلبات مالية 3 (بانتظار الموافقة)، تذاكر العملاء 8 (تحتاج متابعة).
- «صندوق العمل» (12): جدول الطلبات بالأيقونة والوصف، القسم، مقدم الطلب، التاريخ والوقت، الحالة (بانتظار موافقتك / مكتمل / قيد المراجعة)، زر «مراجعة» أو «عرض» وقائمة النقاط الثلاث، ورابط «عرض الكل».
- «إحصائيات السريع»: ثلاث بطاقات أقسام (الموارد البشرية، المالية، خدمة العملاء) مع زر «الدخول»، وسطر نصيحة أسفلها.
- «الوصول السريع»: إجمالي الموظفين 120، الفواتير المعلقة 25، تذاكر العملاء المفتوحة 48.

## التفاعلات
- «مراجعة» تفتح نافذة بتفاصيل الطلب مع زري «اعتماد» و«رفض» تغيّر الحالة وعدد صندوق العمل.
- قائمة النقاط الثلاث: عرض / اعتماد / رفض.
- البطاقات وأزرار «الدخول» والوصول السريع تفتح الصفحات الموجودة: الموارد البشرية ← الخدمة الذاتية/الموظفين، المالية ← لوحة المالية، خدمة العملاء ← لوحة خدمة العملاء، الفواتير المعلقة ← فواتير المبيعات، الموافقات ← الإشعارات.
- «عرض الكل» يعرض كل الطلبات (10 طلبات) في نفس الجدول.

## ملاحظات
- لن يتغير الشريط الجانبي أو الهيدر؛ شكلهم الحالي يبقى كما هو.
- صفحة «سلم الرواتب» تنتقل إلى `/salaries/scale` ويتحدث رابطها في القائمة.
- البيانات تجريبية ولا تُحفظ بعد التحديث.
