# صفحة الوصول البرمجي (API)

صفحة جديدة «الوصول البرمجي (API)» تطابق الصورة، بهوية تكامل بلس الحالية.

## ما سيظهر
- مسار التنقل (الرئيسية ‹ الإعدادات ‹ الوصول البرمجي (API)).
- بانر علوي: «الوصول البرمجي (API)»، «اربط نظامك مع تكامل بلس بكل سهولة وأمان»، الوصف، وأربع مزايا (آمن وموثوق، أداء عالي، تكامل سهل، دعم فني متخصص) مع صورة شريحة API مولّدة.
- أربع بطاقات: إجمالي الطلبات 12,432 (+12%)، الطلبات الناجحة 11,982 (+15%)، الطلبات الفاشلة 450 (5%)، متوسط وقت الاستجابة 320 ms.
- «مفاتيح API الخاصة بك»: جدول (اسم المفتاح، نوع الصلاحيات، تاريخ الإنشاء، تاريخ الانتهاء، آخر استخدام، الحالة، الإجراءات) بثلاث مفاتيح: تطبيق الموارد البشرية، موقع التوظيف، التقارير الخارجية.
- لوحة المفتاح: API Key وAPI Secret مخفيان مع زر إظهار ونسخ، اختيار بيئة (Sandbox) أو (Production)، وزر «إنشاء مفتاح جديد».
- «أمثلة على الاستخدام»: تبويبات cURL / Python / PHP / JavaScript بكود قابل للنسخ، و«عرض المزيد من الأمثلة».
- «المستندات والتوثيق»: أربع بطاقات (سياسات الاستخدام، أمثلة عملية، قائمة نقاط النهاية، دليل المطورين).
- «ملاحظات مهمة» و«تحتاج مساعدة؟» مع زر «تواصل مع الدعم الفني».

## التفاعلات
- إنشاء مفتاح جديد: نافذة (الاسم، الصلاحيات، تاريخ الانتهاء) ويظهر في الجدول مع مفتاح عشوائي.
- الإجراءات: نسخ المفتاح، حذف (مع تأكيد)، وقائمة (تفعيل/إيقاف، عرض).
- إظهار/إخفاء ونسخ الـ Key والـ Secret، وتغيير البيئة يغيّر بادئة المفتاح.
- بطاقات التوثيق تفتح نافذة بمحتوى مختصر (مثلاً قائمة نقاط النهاية).
- زر الدعم يعرض رسالة تأكيد.

## ملاحظات
- تضاف «الوصول البرمجي (API)» للقائمة الجانبية قرب «الإعدادات» دون تغيير باقي العناصر.
- المفاتيح والأرقام تجريبية فقط، ولا يوجد ربط برمجي حقيقي، ولا تُحفظ بعد التحديث.
